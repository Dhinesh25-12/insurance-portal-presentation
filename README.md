## 🚀 Quick Start

### Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Dhinesh25-12/insurance-portal-presentation.git
cd insurance-portal-presentation
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

### Generate Presentation

Run the script to generate the PowerPoint presentation:

```bash
python generate_presentation.py
```

This will create `Insurance_Portal_Application_Demo.pptx` in the current directory.

To customize the presentation, edit `generate_presentation.py`:

- **Colors**: Modify RGB color values (lines with `RGBColor`)
- **Content**: Edit text content in each slide section
- **Layout**: Adjust positioning with `Inches()` values
- **Fonts**: Change font sizes in `Pt()` values
